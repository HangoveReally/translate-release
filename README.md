# HoN Reborn Modification by HangoveR

Лаунчер модов для HoN Reborn на Windows. Русский перевод и пеньки вместо деревьев включаются независимо. Оба режима используют действующий профиль игры.

[Скачать установщик для Windows](https://github.com/HangoveReally/translate-release/releases/latest)

1. Если вы впервые запускаете HoN, откройте игру через Juvio один раз, затем закройте игру и Juvio.
2. Запустите скачанный EXE и завершите установку. Установщик создаст ярлык **HoN Перевод** на рабочем столе.
3. Откройте ярлык, выберите нужные тумблеры, нажмите кнопку запуска, затем **PLAY** в Juvio.

Для обновления закройте игру и Juvio. В окне лаунчера нажмите **Проверить обновления**, затем **Скачать и установить**. После установки лаунчер откроется снова.

Пеньки выключены по умолчанию. Их проверяли в тренировках Caldavar и Mid Wars. Допуск в матчмейкинге пока не подтверждён.

Проект HangoveR. В переводе используются тексты ddgryaz и HoN RU Community (Xyling12) по лицензии MIT. Схема замены деревьев основана на Tree Stumps 1.1 от Doogle.
