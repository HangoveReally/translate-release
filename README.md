# HoN Reborn Translate by HangoveR

Русский перевод интерфейса, обучения и подсказок героев, способностей и предметов в HoN Reborn.

[Скачать установщик для Windows](https://github.com/HangoveReally/translate-release/releases/latest)

1. Если вы впервые запускаете HoN, откройте игру через Juvio один раз, затем закройте игру и Juvio.
2. Запустите скачанный EXE и завершите установку. Установщик сам создаст ярлык **HoN Перевод** на рабочем столе. Откройте этот ярлык.
3. Включите **Русский перевод**, нажмите **Играть на русском**, затем **PLAY** в Juvio.

Чтобы поставить новый выпуск, нажмите **Проверить обновления** в окне перевода. Когда появится **Скачать и установить**, закройте игру и Juvio и нажмите эту кнопку.

Проект HangoveR. В переводе используются тексты ddgryaz и HoN RU Community (Xyling12) по лицензии MIT. Уведомления об авторстве включены в установщик. [Базовый перевод](https://github.com/ddgryaz/hon-ru/tree/8a4cd764237593aa96469cc3074c38c9d030e7d7)
